## 批次 A：7 类后果接口

**文件**：`js/extensions/narrative-consequence.js`

**7 类后果**：
1. `npcRelation`：npcId + delta（好感/关系变化）
2. `sectRelation`：sectId + delta（宗门关系）
3. `cityState`：cityId + flag（城市状态/势力/封锁等）
4. `resourceNode`：nodeId + delta（资源点产出/所有权）
5. `worldFlag`：flagName + value（世界全局标志，影响未来事件）
6. `rumor`：rumorId + text + radius（江湖传闻广播）
7. `futureEventWeight`：eventId + delta（未来事件概率权重）

**API**：
```js
window.NarrativeConsequence = {
  applyConsequence(consequence) → {ok, applied: [{type, ...}]}
  applyConsequences(list) → {ok, applied: [...]}
  scheduleDelayed(consequence, fireDay) → {ok, scheduledId}
  processDay(currentDay) → {fired: [...]}
  cancelScheduled(scheduledId) → bool
  getState() → {consequences, scheduled, worldFlags, rumors, ...}
  getFlag(flagName) → value
  getRumor(rumorId) → rumor
  listNpcRelations(npcId) → array
}
```

**consequence 数据结构**：
```js
{ type: 'npcRelation', npcId: 'a', delta: 10 }
{ type: 'sectRelation', sectId: '少林寺', delta: -5 }
{ type: 'cityState', cityId: '中州', state: 'under_attack' }
{ type: 'resourceNode', nodeId: 'vein_beiming_01', delta: -5 }
{ type: 'worldFlag', flag: 'saved_scattered_cultivator', value: 'true' }
{ type: 'rumor', text: '玩家曾救下散修' }
{ type: 'futureEventWeight', eventId: 'thanking_callback', delta: 30 }
```

**立即应用** vs **延迟**：
- `applyConsequence(c)` → 立即
- `scheduleDelayed(c, fireDay)` → 存到 scheduled，到达 day 自动 processDay 触发

## 批次 B：延迟反馈

**scheduleDelayed**：
```js
{ scheduledId, consequence, fireDay, applied: false, createdDay }
```

**processDay(currentDay)**：
- 遍历 scheduled，找 fireDay ≤ currentDay
- 触发应用 → 标记 applied
- 输出 fired[]

**示例（路线图 §9）**：
- "救下散修" → immediate: npcRelation +50 + createNPC + worldFlag 'saved_scattered_cultivator'
- "5 年后该散修拜入某宗" → scheduleDelayed (day+1800): worldFlag 'cultivator_joined_sect' + futureEventWeight 'sect_leader_callback' +30
- "故人相逢" → scheduleDelayed (day+3650): npcRelation +20 + rumor broadcast

- "放过妖王幼崽" → immediate: worldFlag 'spared_king_offspring' + rumor
- "5 年后成为 Boss" → scheduleDelayed (day+1800): worldFlag 'demon_king_awakened' + futureEventWeight 'demon_invasion' +20
- "遇险时偿还" → scheduleDelayed (day+random 0~1825): futureEventWeight 'demon_rescue' +25

## 批次 C：示例 hook

**`applyConsequence('saved_scattered_cultivator', playerData)`** 一键调用：
```js
function exampleSaveScatteredCultivator(player) {
  return applyConsequences([
    { type: 'npcRelation', npcId: 'scattered_x', delta: 50 },
    { type: 'worldFlag', flag: 'saved_scattered_cultivator', value: player.name + '_' + Date.now() },
    { type: 'rumor', text: '玩家' + player.name + '曾于' + (window.WorldCalendar && window.WorldCalendar.day) + '日救下散修' },
    { type: 'futureEventWeight', eventId: 'cultivator_joins_sect', delta: 30 }
  ]) && scheduleDelayed(
    { type: 'npcRelation', npcId: 'scattered_x', delta: 20, _note: '故人相逢' },
    (window.WorldCalendar && window.WorldCalendar.day || 0) + 3650
  );
}
```

**`applyConsequence('spared_king_offspring', playerData)`** 类似。
