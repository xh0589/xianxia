> 基线：`仙侠世界_v19.0`（v19.0 路线图 P0-1/P0-3 已落地：世界日历 + 宗门职位玩法）。
> 本计划落实 `计划/v18.8内容深度扩展路线图_网页对标版.md` §5 P0-4：每季小比、每年大比，NPC 真实参赛，玩家按职位参与。
>
> 重要发现：v19.0 已落地 90% 地基：
>   - `SectYearGoal.addTournamentWin(sectName)` 钩子（v19.0 批次 C）
>   - 投票 `grand_tournament` 政策（v19.0 批次 D）
>   - `combat-abilities` + 战斗系统（v13.0+）

## 2. 数据契约（公开 API）

### 2.1 真源：`window.TournamentStore`

```js
TournamentStore[sectName] = {
    lastSeason: 0,     // 上次小比（每季 1 次，day%90==0）
    lastYear: 0,      // 上次大比（每年 1 次，day%360==0）
    currentEvent: null, // { id, tier:'season'|'year', openedDay, status:'open'|'running'|'finished', contestants: [{npcId, seed}], bracket: [{...}], winnerId, results: [...] }
    history: [
        // { tier, year, season, winnerId, winnerName, runnerUpId, totalRounds, sectId, finishedDay }
    ]
}
```

### 2.2 公开 API（全部挂 `window`）

| API | 形态 | 用途 |
|---|---|---|
| `openTournament(sectName, tier)` | tier='season'\|'year' → event | 掌门开启大比 |
| `joinTournament(tournamentId, npcId)` | bool | NPC 报名（掌门/长老可代报） |
| `runTournament(tournamentId)` | `{winner, results}` | 掌门下令开始比赛（实跑 NPC vs NPC） |
| `playerParticipate(tournamentId)` | bool | 玩家作为选手报名（弟子及以上） |
| `getTournamentStatus(tournamentId)` | event | 查进度 |
| `getTournamentHistory(sectName)` | array | 查历史 |

### 2.3 事件总线（v19.1 新增）
- `tournament:opened` → payload `{tournamentId, sectName, tier}`
- `tournament:started` → `{tournamentId, totalRounds}`
- `tournament:round` → `{tournamentId, round, results}`
- `tournament:finished` → `{tournamentId, winnerId, winnerName, sectName, tier}`

### 2.4 玩家介入方式（按职位）
- **弟子/外门/内门/亲传**：可作为**选手**报名（`playerParticipate`），用真实战斗 vs NPC
- **长老**：不可参赛；可**代报 NPC** + **下注本门弟子胜率**（影响 morale 收益）
- **掌门**：可**开启/取消**大比 + **下注** + **颁奖**

## 5. 批次实施

### 批次 A：sect-tournament.js 骨架 + 生命周期

**目标**：建文件 + StateRegistry + openTournament/joinTournament/runTournament/getTournamentStatus/getTournamentHistory。**无 UI**。

| 步骤 | 内容 | 自检 |
|---|---|---|
| A1 | 新建 `js/sects/sect-tournament.js` IIFE 骨架 | node --check |
| A2 | `TournamentStore = {}` + `openTournament(sectName, tier)` 内部校验（仅掌门/season+year/7 日窗口） | 掌门开启/玩家开启/重复开启 |
| A3 | `joinTournament(tournamentId, npcId)` | 报名/重复报名/未入 NPC 拒 |
| A4 | `runTournament(tournamentId)`（mock 战斗：用势力+random 决出 winner，不真打） | 4 选手 2 轮出冠军 |
| A5 | `getTournamentStatus / getTournamentHistory` | 序列化正确 |
| A6 | StateRegistry 'sectTournaments' v1 | export/import/reset |

**完成定义**：node 单元测试 ≥ 20 条；不开 UI。

### 批次 B：NPC 真实参赛（战斗系统复用）

**目标**：runTournament 真打 NPC vs NPC 战斗（用 `battle-system` 简化逻辑），势力调整（外门 +0、内门 +0、亲传 +1、长老 ±0 → 隐式加成）。

| 步骤 | 内容 |
|---|---|
| B1 | 工具 `getNpcPower(npc)` 读 NPC realm + 战斗属性 |
| B2 | `simulateNpcBattle(npcA, npcB, sectA, sectB)` 改用 `getNpcPower` 决胜负 |
| B3 | `runTournament` 改用 `simulateNpcBattle` 跑单败淘汰 |
| B4 | 胜利调 `addTournamentWin(sectName)` + 写入 history |
| B5 | 失败 / 平局边界 |

**完成定义**：4 NPC 2 轮出真实胜者（不可纯随机）。

### 批次 C：玩家参与

**目标**：玩家按职位介入大比。

| 步骤 | 内容 |
|---|---|
| C1 | `playerParticipate(tournamentId)`：弟子及以上可报名；写入 `contestants: [{type:'player', entity:...}]` |
| C2 | `runTournament` 遇到 player 时调 `startBattle(playerEntity, npcEntity)` 真打 |
| C3 | 长老/掌门 `withdrawContestant(tournamentId, npcId)` 撤销 |
| C4 | 掌门 `setTournamentPolicy('cancel' / 'postpone')` |

**完成定义**：玩家作为选手可与 NPC 真打一场。

### 批次 D：周期调度 + UI 集成

**目标**：每季小比 / 每年大比 / 宗门面板加 UI。

| 步骤 | 内容 |
|---|---|
| D1 | `Tournament.tickDay(sectName, day)` 接 processAllSectDailyEconomy 末尾：day%90==0 自动开小比、day%360==0 自动开大比 |
| D2 | `showTournamentPanel(sectName)` 模态：当前/历史/规则 |
| D3 | `showSectDeepOverview` 加 "🏆 大比" 按钮（按职位显示不同操作） |
| D4 | WorldCalendar 注册"小比 day N / 大比 day N"事件 |
| D5 | `setSectDeepOverview` 接入"🏆 大比"按钮 |

**完成定义**：day=90 自动开小比；day=360 自动开大比。

### 批次 E（可选，留 v19.2）
- NPC 弟子 vs 邻派 NPC（门派间大比）
- 大比赌注系统（灵石下注）

## 9. 风险与不做清单

### 风险
- **R1 战斗属性过强**：NPC 实力远超玩家 → 玩家每战必输。**缓解**：按 sect 势力 +0~+2 加成；玩家 hidden 加成 +1（玩家难度不应比 NPC 高）
- **R2 周期调度的"已经开过"**：`lastSeason / lastYear` 字段如果丢失会重开。**缓解**：tickDay 严格按 day 计算
- **R3 玩家参加时缺 Entity**：需 `buildPlayerBattleEntity(currentCharData)` 复用 v12.7 的工具

### 明确不做（v19.1）
- 跨门派大比（v19.2）
- 玩家手动下注灵石（v19.2）
- 大比战报 PDF（v19.2）
