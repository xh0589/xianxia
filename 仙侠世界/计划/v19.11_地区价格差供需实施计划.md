## 批次 A：6 城市 × 6 类别

**文件**：`js/extensions/market-dynamic.js`

**6 城市**（路线图 §1.2 七大区，去掉"秘境虚空"）：
- 中州、南疆、东海、西荒、北冥、天空

**6 类别**（路线图 §4 P1-8）：
- 丹药 (pill)
- 药材 (herb)
- 矿材 (mine)
- 法器 (weapon)
- 食物 (food)
- 符箓 (talisman)

**36 指数**：`{cityId: {category: {supply, demand, basePriceMul, eventMods:[]}}}`
- 初始 supply=100, demand=100, basePriceMul=1.0
- 价格公式：mul = basePriceMul × (demand / supply) × (1 + sum(eventMods))

## 批次 B：5 个供需来源

1. **地区产出**：每城市有基础倾向（东海鱼多 → 食物 baseMul 0.8；西荒金多 → 矿材 0.7）
2. **世界事件**：灵气潮 → 丹药 demand +30；兽潮 → 丹药 demand +20、矿材 -10
3. **宗门战争**：参与者 → 法器/符箓 demand +20；战后 → 法器 supply +50
4. **玩家大量买卖**：玩家 sell > 阈值 → 该商品 supply +20；buy > 阈值 → supply -10
5. **NPC 大规模需求**：每 tickDay 随机 NPC 事件 → 某城市某类别 demand +15

## 批次 C：世界事件

**10 个事件**：
- spirit_tide (灵气潮) → 丹药需求 +30
- beast_flood (兽潮) → 丹药需求 +20、矿材供应 +10
- war_start (宗门战起) → 法器需求 +25、符箓需求 +15
- war_end (宗门战终) → 法器供应 +50、符箓供应 +20
- plague (瘟疫) → 药材需求 +20、解毒丹 +30
- festival (节庆) → 食物需求 +15
- discovery (秘境发现) → 矿材需求 +10
- sect_sale (宗门拍卖) → 法器供应 +30
- harvest (丰收) → 药材供应 +20
- cold (大寒) → 寒性药材需求 +20

每个事件：activeDays / affectedCities / categoryMods

## 批次 D：NPC 需求（独立钩）

5 个 NPC 需求事件（per tickDay 概率触发）：
- 某 NPC 求购某种丹药 → 该城市该类别 demand +15
- 某 NPC 急需某材料 → 该城市该类别 demand +20
- ...

## 批次 E：API + StateRegistry

```js
window.MarketDynamic = {
  getIndex(cityId, category) → {supply, demand, mul, mods}
  priceMul(cityId, itemCategory) → mul
  adjustFromTrade(cityId, category, qty, isBuy) → {newMul}
  applyWorldEvent(eventId) → {ok, mods}
  tickDay() → {events:[], npcNeeds:[]}
  listActiveEvents() → array
  getState() → {indices, activeEvents, history}
}
```

**StateRegistry v1** `marketConfig`
- indices: {cityId: {category: {...}}}
- activeEvents: [{id, startDay, expireDay, mods}]
- history: 最近 20 次事件

**事件总线 3 个**：
- `market:event:applied` / `market:npcNeed` / `market:priceChange`
