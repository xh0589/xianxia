## 批次 A：兽潮事件

**文件**：`js/extensions/beast-tide.js`

**10 兽潮等级 + 5 稀有灵兽池**：

| 等级 | 名称 | 持续 | 灵兽池变化 |
|---|---|---|---|
| tide_1 | 小兽潮 | 7 天 | 灵兽出现率 +20% |
| tide_3 | 中兽潮 | 14 天 | + 1 稀有灵兽 |
| tide_5 | 大兽潮 | 21 天 | + 2 稀有灵兽 + 妖兽入侵 |
| tide_7 | 巨兽潮 | 30 天 | + 3 稀有灵兽 + 灵脉争夺 |
| tide_10 | 天灾级 | 60 天 | 全部稀有 + 仙禽出现 |

**稀有池**（10 种，仅在兽潮出现）：
- 雷鹰 (thunder_eagle)
- 龙龟 (dragon_turtle)
- 火凤 (fire_phoenix)
- 玄龟 (xuan_gui)
- 雷兽 (thunder_beast)
- 仙鹤 (crane)
- 黑熊 (black_bear)
- 五色鹿 (five_color_deer) - 仙级
- 金乌 (golden_crow) - 神话
- 鲲鹏 (kunpeng) - 神话

**API**：
```js
window.BeastTide = {
  triggerTide(level, opts) → {ok, tideId, duration, rareAdded}
  endTide(tideId) → {ok}
  tickDay() → {active: []}
  getActiveTide() → tide | null
  isRaidActive() → bool
  getRarityBoost() → number  // 0~3
  getCurrentPool() → ['beast_lingfox', ...]  // 当前可用灵兽
  getState() → {tides: {}}
  listTideLevels() → array
}
```

## 批次 B：捕捉池修改

**getCurrentPool**：
- 基础池 = v19.12 BEAST_DISTRIBUTION 所有灵兽
- 兽潮 active 时附加稀有池
- getCurrentPool() 返回合并列表（去重）

## 批次 C：灵兽园

**5 宗门可建**（名额限制）：
- 任意宗门 ID 可建
- 每园 30 天建设 + 100 灵石
- 园效果：园内灵兽训练 +20% / buff 持续 +50%

**API**：
```js
window.BeastGarden = {
  build(sectId, opts) → {ok, gardenId, cost}
  remove(gardenId) → bool
  addBeast(gardenId, beastId) → bool
  removeBeast(gardenId, beastId) → bool
  getBuff(sectId) → {trainingPct, buffMul}
  tickDay() → {events: []}
  getState() → {gardens: {}}
  listGardens(sectId) → array
}
```
