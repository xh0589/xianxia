# v19.9 动态秘境 P1-6 实施计划

> 对标 v18.8 路线图 §4 P1-6：从固定 3 类楼层副本扩展为动态秘境。
> 验收：保留现有 3 类常驻秘境；新增动态秘境生成器（种子+主题+资源+流派解法）；5~10 房每房 1 事件。

## 设计宪法

- 单一真源 + StateRegistry v1 + 镜像非真源
- 不复制战斗/存档系统
- 不引入"日限 N 次"配额
- 六大报告点 + 7 条禁止
- 不动 `DUNGEON_DEFS` 既有 3 类常驻秘境
- **零侵入**：动态秘境作为新模块，常驻秘境可选择性接入新事件池

**8 模板**：

3. **药王遗府**：6-8 月开 14 天，env alchemy，资源药材，建议筑基+，流派炼丹/医术
4. **海底龙宫**：3-4 月大潮后开 21 天，env water，资源水精，建议金丹+，流派灵兽
5. **枯骨渊**：10-12 月开 30 天，env dark，资源阴魂，建议筑基+，流派阴魂/符箓
6. **九幽幻境**：随机 1/60 日，env illusion，资源幻晶，建议元婴+，流派阵法
7. **云海仙阙**：7-9 月开 14 天，env cloud，资源云精，建议金丹+，流派飞剑
8. **五行禁地**：每月 1/15 日开 7 天，env 5e，资源五行精华，建议金丹+，流派阵法

## 批次 B：房间事件池

**6 个事件类型**：
- `combat`：战斗房（默认解法 1.0）
- `puzzle`：解谜房（炼丹/医术/阵法）
- `chance`：奇遇房（随机 buff/debuff）
- `treasure`：宝藏房（资源/材料/法器）
- `trap`：陷阱房（符箓/灵根优势避）
- `boss`：首领房（流派解法 + 剑主战）

**示例事件池（每个秘境 5~8 个事件）**：
- 雷泽洞天：thunder_cave_combat / thunder_cave_puzzle / thunder_cave_treasure / ...
- 古战场：ghost_field_combat / soul_calm_puzzle / cursed_treasure / ...
- 药王遗府：alchemy_room_puzzle / herb_garden_treasure / poison_trap / ...

**流派解法系数**：solution 1.2 → 难度降低 20%，获得额外奖励 1.5x

## 批次 C：探索 API

```js
window.DungeonDynamic = {
  listActive() → array                // 当前活动秘境
  generateDaily(worldDay, worldMonth) → array  // 每日检查生成/消失
  enter(dungeonId) → {ok, dungeon, roomCount, firstRoom}
  exploreRoom(dungeonId, choice) → {ok, room, event, result, reward?, nextRoom}
  leave(dungeonId) → {ok, totalReward, explored}
  complete(dungeonId) → {ok, title?, bigReward}
  getPlayerProgress(dungeonId) → {roomsCleared, totalReward}
  listTemplates() → array
  getState() → {active, progress, history}
}
```

**exploreRoom 校验**：当前房间索引有效 / choice 必须从 event.options 选
**result 计算**：基于 solution 系数 + 玩家技能 + 随机

## 批次 D：StateRegistry + 事件总线

**StateRegistry v1** `dungeonDynamic`
- active: [{id, openedDay, closeDay, region, ...}]
- progress: { [dungeonId]: { roomsCleared, totalReward, startedDay } }
- history: 最近 20 次秘境完成

**事件总线 4 个**：
- `dungeon:dynamic:spawn` / `:close` / `:enter` / `:complete`
