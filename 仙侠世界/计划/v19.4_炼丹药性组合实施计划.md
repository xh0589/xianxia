# v19.4 炼丹药性组合 P1-1 实施计划

> 对标 v18.8 路线图 §4 P1-1：把炼丹从"固定配方"扩展为"药性组合"流派。
> 验收：筑基丹等关键丹可由"主药+辅药+调和"组合，火候/技能决定品质；毒性过高生成"有瑕"变体。

## 设计宪法（不变）

- 单一真源 + StateRegistry v1 + 镜像非真源
- 不复制战斗/存档系统
- 不引入"日限 N 次"配额
- 六大报告点 + 7 条禁止
- 兼容：v19.3 已落地，npcLineageIndex / 既有 crafting.js 全部不动主流程

## 范围

| 在做 | 不做 |

| 药材新增 4 维：五行/药性/主效/毒性 | 全部 100 配方重写 |

## 批次 A：基础数据 + 旧流程零侵入

**文件**：`js/crafting.js` 末尾追加 `PILFAR_MATERIAL_PROPS`（25+ 种药材的 4 维属性）
**内容**：
- 五行：金/木/水/火/土
- 药性：cold(0) / cool(40) / neutral(50) / warm(60) / hot(80)，归一化到 0~100
- 主效：heal(疗伤) / qi(回气) / breakthrough(突破) / divine(神识) / body(炼体) / detox(解毒)
- 毒性：0~100

不动 `executeCrafting` 主流程，**旧配方继续走原路径**。

## 批次 B：药性组合丹方（v19.4 新配方）

**文件**：`js/crafting.js` 追加 `compoundPilferRecipes`（5~8 张关键丹的"开放槽"版本）
**结构**：
```js
{
  id: 'recipe_zhuji_open',
  name: '筑基丹·开放',
  category: 'pilfer',
  requiredSkills: { 炼制: 50 },
  slots: {
    main: { minElement: { wood:30, water:20 }, minPrimary: { breakthrough:80 }, minNature: 60, maxToxic: 60 },
    assist: { minPrimary: { qi:30, heal:20 }, maxToxic: 40, count: 2 },
    balancer: { maxToxic: 30, count: 1 }
  },
  result: { itemId: 'pill_zhuji', count: 1, allowFlaw: true },
  qiCost: 50, timeCost: 60
}
```
**说明**：玩家从背包里挑符合槽位的药材；不强制 ID，按属性匹配。

## 批次 C：执行流 `executeCompoundPilfar`（v19.4 路径）

**新增函数** `executeCompoundPilfar(recipeId, slotPick)`：
- `slotPick = { main: 'mat_thousand_lingzhi', assist: ['mat_lingzhi','mat_snow_lotus'], balancer: ['mat_ginseng'] }`
- 验证每槽药性 / 主效 / 毒性 / 五行是否在 recipe.slots 范围内
- 评分：药性匹配度 + 主效匹配度 + 五行补益 − 毒性惩罚
- 火候：炼丹技能 ≥ 要求 + 随机 ±20
- 品质：0~100 → 劣/普通/优良/杰出
- 毒性 > `flawThreshold` (60) → 自动改 itemId 为 `pill_zhuji_flaw`
- 毒扣 30% 生命
- 落常规 craft 流程的：材料消耗 / 时间推进 / 事件总线

**事件总线新增**：`alchemy:compound:success` / `:flaw` / `:fail`

## 批次 D：StateRegistry + 副作用 + 有瑕变体

**StateRegistry v1 注册** `alchemyConfig`（只存"有瑕变体"列表 + 玩家上次评分，用于追踪玩家流派）

**副作用零侵入**：
- 旧 fixed recipe 完全不进入 `executeCompoundPilfar`
- executeCrafting 末尾不动
- UI 列表先只读 recipe 名字，加 `tags: ['开放配方']` 标记

**有瑕变体**：
- `pill_zhuji_flaw` 自动克隆 `pill_zhuji` + `tags: ['有瑕']` + effect -30%
- `pill_zhuji_imperial`（极品）当品质=杰出且毒性=0

## 风险

- R1 性能：评分函数涉及数组 reduce+每槽多属性 → 100ms/配方以内，<0.2s 可接受
- R2 玩家误选：高毒性自动 flaw + 毒扣 30% 血，禁止 silent
- R3 旧数据兼容：旧 `pilferRecipes` 不动；新 compoundPilferRecipes 走独立路径
- R4 背包取材料：批次 B 选用 `_takeFromInventory(ids)` 复用 v19.x 既有 helper
