# bug-scanner 使用说明（v2.0 · 2026-10-05 评审采刀后）

静态断链扫描器：专治「全局变量接缝」风格的无框架纯 JS 工程——文件间靠
window.* / 顶层 var/function 互通、defer 串行加载、无模块系统。
不求 100% 准确，只产出「疑似 BUG 的文件与行号」供人工快判。

## 用法

```
node tools/bug-scanner.js [游戏根目录]        # 默认当前目录
node tools/bug-scanner.js /path/to/仙侠目录
```

输出：控制台摘要 + 根目录 `tools/bug-report.txt`（按置信度排序）。
零依赖，Node ≥ 14 即可。

## 检测分类（v2.0 按置信度自动筛）

| 标签 | 检测 | 置信 |
|---|---|---|
| SCRIPT-MISSING | html 引用了不存在的 js 文件 | 必真 |
| **NEAR-MISS** ★v2新增 | 消费 window.X 无定义，但存在**近邻真身**（拼写/大小写/单复数/中间插词断链）——自动给出真身位置与多候选 | 高 |
| EXPORT-UNDEF | 顶层 `window.X = X` 裸符号无定义——该行抛 ReferenceError，**本文件其后顶层语句全部静默失效** | 高 |
| SUSPEND-CONSUMED | 悬空文件（不在加载序列）导出的全局被挂载文件消费 | 高 |
| INLINE-UNBOUND | onclick="fn()"（含模板串里的）fn 未挂全局——点击必炸 | 高 |
| CONSUME-GHOST | 消费 window.X 全工程无定义。直接调用=中（幽灵）；守卫式=低（可能是可选注入点——**与 NEAR-MISS 联动后有近邻即升 NEAR**） | 中/低 |
| DOM-ID-MISSING | getElementById('X') 字面量全工程无源（含字符串池兜底） | 中 |
| DUP-EXPORT | 多文件挂载**按右值形态分型**：幂等 init/合账(+=、||0)/装饰器(orig/apply)/分片守卫(!window.X) → 信息档良性；未识别形态才报低档 | 低/信息 |
| DEAD-FILE | js/ 存在但未挂载（对账用） | 信息 |

## NEAR-MISS 近邻五规则（v2 核心）

归一相等（大小写/下划线）· 编辑距离≤2（双 5 字门槛）· 长名包含（差≤4）·
词级差 1 词（保序）· 共同前后缀（前≥8 后≥6 差≤4，抓 story→storyline 词内变体）。
原生 API 不算真身；最多列 3 候选供人判。
