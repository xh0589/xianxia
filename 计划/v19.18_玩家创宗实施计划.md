## 批次 A：玩家创宗

**文件**：`js/extensions/player-sect.js`

**5 资源**（路线图 §13 "3 种相互竞争资源决策"）：
- spiritStones（灵石）
- disciples（弟子数）
- reputation（声望）
- elixir（丹药储备）
- weapon（法器储备）

**创宗 API**：
```js
window.PlayerSect = {
  create({name, alignment, location, founder}) → {ok, sectId, instance}
  dissolve(sectId) → {ok, reason, transfers}
  rename(sectId, newName) → {ok}
  setAlignment(sectId, alignment) → {ok}
  getSect(sectId) → instance
  listMySects() → array
  // 资源
  getResource(sectId, type) → number
  addResource(sectId, type, qty) → bool
  consumeResource(sectId, type, qty) → {ok, remaining} | {ok: false, reason: 'insufficient'}
  // 弟子
  recruitDisciple(sectId, npcId) → {ok, discipleId}
  dismissDisciple(sectId, discipleId) → bool
  listDisciples(sectId) → array
  // 职位
  assignPosition(sectId, npcId, position) → {ok} | {ok: false, reason: 'slot-busy'}
  getDisciple(sectId, npcId) → disciple
  // 资源生产/消费
  setProductionRule(sectId, type, qtyPerDay) → {ok}
  setConsumptionRule(sectId, type, qtyPerDay) → {ok}
  tickDay() → {produced, consumed, balances}
  // 决策
  focusPolicy(sectId, policy) → {ok}  // 'expand'|'internal'|'militarize'
  getPolicy(sectId) → string
  getState() → {sects: {}}
}
```

**sect 实例**：
```js
{
  id: 'psect_<founder>_<timestamp>',
  name, alignment, location, founder,
  createdDay,
  resources: {spiritStones: 100, disciples: 0, reputation: 10, elixir: 0, weapon: 0},
  disciples: [{npcId, joinedDay, position}],
  production: {spiritStones: 5, disciples: 0, reputation: 0.1, elixir: 1, weapon: 1},
  consumption: {spiritStones: 1, disciples: 0, reputation: 0, elixir: 0, weapon: 0},
  policy: 'internal',
  rank: 1,
  history: []
}
```

## 批次 B：3 互竞争决策

**政策选择**（路线图 §13 第二阶段"3 种资源决策"）：
- `expand`（扩张）：弟子招募 +1/天，资源消耗 ×1.5
- `internal`（内政）：资源生产 +30%
- `militarize`（备战）：武器生产 ×2，但弟子流失 +0.5/天

**每日 tickDay**：
- 根据 production 增
- 根据 consumption 减
- 根据 policy 加成
- 资源 ≤ 0 → 警告（不崩溃）
