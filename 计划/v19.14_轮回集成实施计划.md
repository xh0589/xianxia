## 批次 A：死亡集成 + onPlayerDeath

**新文件**：`js/extensions/reincarnation-integration.js`

**导出**：
```js
window.ReincarnationIntegration = {
  onPlayerDeath(reason) → {ok, summary, legacyPoints}
  openReincarnationModal(summary) → void
  applyInheritanceToNewLife(newChar, selections) → {ok, newChar}
  applyLegacyToNewWorld(records) → {ok, descendants:[], steles:[]}
  createNPCDescendant(record) → {npcId, name, ...}
  markStele(record) → {steleId, text, ...}
}
```

**onPlayerDeath** 流程：
1. 从 `window.currentCharData` 读取玩家数据
2. 调 `Reincarnation.startReincarnation(playerData, reason)`
3. 调 `Reincarnation.preserveWorldMemory(playerData)` 写前世传说
4. `ReincarnationIntegration.openReincarnationModal(summary)` 弹模态
5. 玩家选 5 选 N → `Reincarnation.grantInheritance` 各次
6. 选完点"转世" → 调 `window.startNewGamePlus()` 走原 NG+ 流程

**reason 决策**：
- hp=0 战斗死亡 → 'death-combat'
- age ≥ maxAge 寿终 → 'death-natural'
- 主动飞升 UI → 'ascend'
- 主动转世 UI → 'voluntary'

## 批次 C：startNewGamePlus 集成

**新文件**：`js/extensions/reincarnation-integration.js`（继续）

**不重写** `startNewGamePlus()`，仅在它执行时检查 `Reincarnation.nextLifeInheritance.granted`：
- 若有 granted 记录 → 在创建新角色时应用
- 通过 `window.applyReincarnationToNewChar` 钩子（兼容模式：若新存档系统支持）

> 若 `startNewGamePlus()` 在 app.js 且不可改 → v19.14 提供 `wrapStartNewGamePlus()` 包装函数：
```js
window.wrapStartNewGamePlus = function (origFn) {
    return function () {
        var args = arguments;
        // 先调 reincarnation 应用
        var nextChar = ReincarnationIntegration.buildNewCharFromInheritance();
        if (nextChar) {
            // 用 nextChar 作为 name/sex 输入
            origFn.call(this, nextChar.name, nextChar.sex);
        } else {
            origFn.apply(this, args);
        }
    };
};
```

## 批次 D：前世传说影响新世界

**`applyLegacyToNewWorld(records)`**：
- 每条 record：
  - `had-children` → 在 record.finalRealm 匹配的 NPC 中找 1 个 → 创建"XXX之孙"子嗣（age 15~25）
  - `founded-sect` → 给所有 sect 标记 "传说：XXX所创"
  - `saved-sect` → 标记"前代 XXX 曾救此宗"
  - `discovered` → 标记某些秘境有"XXX发现"传说
  - `won-tournament` → 标记某些宗门有"XXX曾连冠"
  - `married` → 标记"XXX之伴侣" 关系链
- 输出 `descendants[]` + `steles[]` + `worldFlags[]`
- 注入到 `npcManager`（真实创建子嗣）和 `world.flags`（传说标记）

**createNPCDescendant(record)**：
```js
{ npcId: 'descendant_' + record.worldDay + '_' + idx,
  name: record.playerName + randomSurname,  // 用命名系统
  age: 15 + Math.floor(Math.random() * 10),
  realm: descendantOf(record.finalRealm, 2),  // 降 2 大境界
  sectId: record.sectId || null,
  legacy: '前代' + record.playerName + '之' + (Math.random() < 0.5 ? '孙' : '后人'),
  _legacyRef: record.recordDay
}
```

> 真实创建 NPC 由 `npcManager.createNPC(descendant)` 完成（v19.14 通过 EventBus 触发）
> 若 npcManager 不存在 → 缓存到 `_pendingDescendants[]`，下次加载应用
