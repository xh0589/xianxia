## 批次 A：进化系统

**文件**：`js/extensions/beast-evolution.js`

**3 进化线**（每条对应路线图 §7.2 提到的稀有化）：
1. `line_fox`（灵狐系）：幼狐 → 灵狐 → 九尾灵狐（buff: treasure +5% → +15% → +30%）
2. `line_phoenix`（火凤系）：幼凤 → 火凤 → 朱雀（buff: craftFire +10% → +20% → +35%）
3. `line_dragon`（龙龟系）：幼龟 → 灵龟 → 玄龙（buff: carry +10% → +25% → +50%）

**进化条件**：
- 幼→成：等级 20 + 与玩家契约 ≥ 50 天
- 成→王：等级 50 + 经验 ≥ 1000 + 玩家好感 ≥ 80

**API**：
```js
window.BeastEvolution = {
  // 进化
  canEvolve(beastId) → {ok, nextStage, requirements, missing: []}
  evolve(beastId) → {ok, fromStage, toStage, newBuff}
  getStage(beastId) → 'infant'|'adult'|'king'
  getLine(beastId) → lineId | null
  // 经验
  addExp(beastId, exp) → {ok, newLevel, leveledUp, evoReady}
  getLevel(beastId) → number
  getExp(beastId) → number
  // 状态
  getState() → {beasts: {beastId: {stage, line, exp, level, bondDays, ...}}}
  initBeast(beastId, lineId) → {ok}
  listLines() → array
}
```

## 批次 B：受伤/休养

**受伤机制**：
- 战斗 → 受伤（hp 减 30~50%）
- tickDay 休养 1% 自动恢复
- 治疗（用丹药）：3 种丹药 → +20%/+40%/+60%
- 满血 100 / 受伤 0~50% / 重伤 < 30%

**API**：
```js
window.BeastHealing = {
  damage(beastId, hpLost) → {ok, currentHp, isWounded}
  heal(beastId, itemId) → {ok, amount, full}
  tickDay() → {healed: []}
  getHp(beastId) → number
  getMaxHp(beastId) → number
  getWoundStatus(beastId) → 'healthy'|'wounded'|'critical'
  consumePill(beastId, pillType) → {ok, heal}
  // pillType: 'minor'|'medium'|'major'
  getState() → {beasts: {beastId: {hp, maxHp, status}}}
}
```

## 批次 C：变异/遗传

**变异**：
- 玩家喂食"变异丹" → 10% 概率触发变异
- 变异产生新特性（buff × 1.5 + 随机稀有属性）

**遗传**：
- 两只同 line 灵兽繁殖 → 子代继承父/母特性 50%
- 10% 概率继承双方最强特性

**API**：
```js
window.BeastMutation = {
  tryMutate(beastId) → {ok, mutated, newTrait, rareAttr}
  breed(parentAId, parentBId) → {ok, childId, inheritedTraits: []}
  getMutationRate() → 0.10
  getState() → {beasts: {beastId: {traits, mutated}}}
}
```
