# v19.5 炼器·材料词缀 P1-2 实施计划

> 对标 v18.8 路线图 §4 P1-2：让材料决定法器，而不是配方决定全部属性。
> 验收：法器 = 器胚 + 主材 + 辅材 + 铭纹/阵纹；主材标签→1~3 词缀；炼器技能决定保留想要词缀的能力。

## 设计宪法

- 单一真源 + StateRegistry v1 + 镜像非真源
- 不复制战斗/存档系统
- 不引入"日限 N 次"配额
- 六大报告点 + 7 条禁止
- 不动 crafting.js 旧 fixed 路径；新走 `executeCompoundForging`

## 范围

| 在做 | 不做 |
|---|---|
| 7 类材料标签（玄铁/雷晶/凤羽/阴魂/龙类/陨铁/星辰） | UI 入口面板 |
| 5 类器胚（剑胚/刀胚/甲胚/飞剑胚/重兵胚） | 替换所有 forgingRecipes |
| 15 个候选词缀（属性/词缀混合） | 战斗效果真实计算 |
| 5 张开放炼器方（自由选材） | 武器词缀对战斗真实加成 |
| executeCompoundForging 评分 + 词缀抽取 | 器胚耐久/修复 |
| 铭纹/阵纹槽（1~2） | 跨材料连锁反应 |
| 单元测试 ≥ 30 条 | 浏览器 e2e 端到端 |

## 批次 A：材料标签 + 词缀池

**文件**：`js/crafting/forging-compound.js`
**内容**：
- `MATERIAL_TAGS` 映射 30+ mat_ → tag 数组（玄铁/雷晶/凤羽/阴魂/龙类/陨铁/星辰/秘银/寒铁/火晶/紫金/铜/兽骨）
- `AFFIX_POOL` 15 个候选词缀：{key, name, attrKey, attrVal, damageType?, weight, minForgeSkill}
  - 玄铁系列：坚固(+def), 厚重(+durability), 反震(2% reflect)
  - 雷晶系列：雷击(+thunder dmg), 麻痹(5% proc stun 1 回合)
  - 凤羽系列：炽焰(+fire dmg), 疾风(+speed), 涅槃(死亡 10% 复活)
  - 阴魂：噬魂(+divine), 诅咒(3% proc -def)
  - 龙类：龙威(+hp), 龙息(+fire+thunder)
  - 陨铁：碎星(+crit), 星陨(范围攻击)
  - 星辰：聚灵(+qi regen), 通天(+divine)
  - 通用：锋利(+atk), 轻灵(-weight), 精密(+crit)

```js
    assist: { count: 2 },
    rune: { count: 1, optional: true, minForgeSkill: 40 }
  },
  result: { itemId: 'wpn_sword_open', count: 1, namePrefix: true, allowImprint: true },
  qiCost: 50, timeCost: 40
}
```

## 批次 D：executeCompoundForging

- `slotPick = { embryo, main:['mat_xxx'], assist:['mat_xxx','mat_yyy'], rune:['mat_zzz'] }`
- 校验：器胚 type 匹配；材料在 inventory；技能 ≥
- 抽词缀：每材料按其 tags 抽 1~2 个候选 affix
- 炼器技能 = "保留想要词缀" 的概率：`keep = min(0.95, 0.4 + skill*0.005)`
- 词缀写入 item：`affixes = [{key, name, attrKey?, attrVal?, proc?}]`
- 命名：词缀名 + 器胚名（如 "坚固·寒铁剑胚"）
- 写入 `attrs`/`combatBonus`/`damageType` 字段
- StateRegistry `forgingConfig`（最近 20 武器 + 玩家流派：偏好"重剑"/"灵巧"）
- 事件总线：`forging:compound:success/:imprint/:fail`

## 风险

- R1 性能：每词缀权重 + reduce + 多次随机；100 次 < 200ms 可接受
- R2 旧数据：不动 forgingRecipes
- R3 词缀爆炸：affix 池 15 个，5 类材料标签 → 限定 1~3 个；不暴露
- R4 铭纹：rune optional 缺省时跳过；rune 必须 ≥ 锻造 40
