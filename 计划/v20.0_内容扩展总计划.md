> 依据：35 项游玩内容缺口分析（对照鬼谷八荒 / 觅长生 / 太吾绘卷 / 了不起的修仙模拟器）+ 三份审查报告（STRUCTURE核对 / 游戏BUG与设计审查 / 引用完整性机械扫描）。

## 第 1 层·十大标志性玩法（从零设计实装）

> 按仙侠标志度 × 玩家可感知 排序。每项给：标志度 / 现状 / 设计要点 / 工程量 / 涉及文件 / 依赖 / 验收。

### 1.1 天劫/渡劫战【标志度★★★★★，完全没有】
- **现状**：渡劫台地点只弹文案"雷光隐隐，突破感悟加深"，无任何天劫战斗。鬼谷/觅长生/了不起三款核心。
- **设计要点**：
  1. 渡劫期 9 层满触发 `triggerHeavenlyTribulation`：3-9 波雷劫战斗（波数随境界增），每波间可服丹/调息
  2. 中段心魔劫（用 0.2.3 心魔系统）：心魔化身挑战，败则走火入魔
  3. 可请道侣/同门护法（用 0.2.6 双修合击 + 队伍系统），护法者分担雷劫
  4. 渡劫失败：肉身毁→soul-state 残魂态（已实现），或直接身死→转世（见 1.7）
  5. 渡劫成功→飞升结局（见 1.3）
  6. 雷劫有概率掉落雷劫液（炼器/炼丹稀有材料）
- **工程量**：~700 行
- **涉及**：新建 `js/cultivation/heavenly-tribulation.js`、`js/cultivation/breakthrough-ritual.js`、`js/location-system.js`(渡劫台)、`js/core/soul-state.js`、`js/battle.js`(雷劫战斗实体)
- **依赖**：0.2.1（境界质变）、0.2.3（心魔）、0.2.6（护法）、1.3（飞升后）
- **验收**：渡劫期有多波雷劫实战、心魔劫、可请护法、失败可转世/残魂、成功飞升。
- **决策点**：① 雷劫波数公式（固定×境界 还是 随机×境界）；② 心魔劫是否一票否决（败即走火入魔）。

### 1.2 主动招式系统【标志度★★★★★，完全没有】
- **现状**：战斗只选部位 `playerAttack(partId)`，无主动选技能/真气管理/招式相克。鬼谷/觅长生核心。**战斗单调最大根因。**
- **设计要点**：
  1. 战斗 UI 增招式栏：显示已装备功法的 attackMoves（SKILL_ATTACK_MOVES 已定义于 equipment.js:9，未接）
  2. 招式有 qiCost/staminaCost/hitBonus/armorPenetration/damageType/damageMult/partPreference
  3. 选招式→选部位→释放；招式有 CD 或连击点
  4. 真气管理：招式消耗真气，普攻回气，逼玩家做资源博弈
  5. 招式元素克制（用 0.2.2 五行）：火招打木敌 +20%
  6. 招式与 build 分化联动（见 2.2 剑/体/法修）
  7. 敌人也主动放招式（修 enemyTurn 增技能选择层，配合 COMBAT_ABILITIES 已有的 9+4 绝技）
- **工程量**：~900 行
- **涉及**：`js/battle.js`(playerAttackWithMove 已存:2006 但未充分用)、`js/equipment.js`、`js/app.js`(战斗 UI)、新建 `js/combat/move-system.js`
- **依赖**：0.2.2（灵根五行）、0.2.7（招式 damageType 修复）
- **验收**：战斗可主动选招式释放、有真气/CD管理、招式相克生效、敌人也会放技。
- **决策点**：① CD 制还是连击点制；② 招式解锁靠熟练度还是功法直接给。

### 1.3 飞升后世界【标志度★★★★★，完全没有】
- **现状**：飞升后"天界之门为你敞开"后黑屏。觅长生飞升后是新的开始。
- **设计要点**：
  1. 飞升→天界新地图（1.10 高位面地图的子集，先做天界一块）
  2. 天界日常：仙人切磋（高难战斗）、天界事务（每日小抉择）、下界香火反馈（凡间信徒供奉回馈真元）
  3. 香火系统：飞升前在凡间收信徒/立道统，飞升后香火越旺真元产出越高
  4. 天界有新功法/新材料（雷劫液/天材）供飞升后继续养成
  5. 二段飞升（天仙→金仙）作为终极目标
- **工程量**：~600 行（最小可玩版）/ ~1200 行（完整版）
- **涉及**：新建 `js/endgame/ascension-epilogue.js`、`js/endgame/incense-faith.js`、`js/location-system.js`(天界地图)
- **依赖**：1.1（渡劫成功才飞升）、0.2.1（境界质变）
- **验收**：飞升后天界可探索、有日常循环、香火反馈真元、有二段飞升目标。
- **决策点**：最小沙盒(~600行) 还是完整天界(~1200行)。

### 1.4 NPC 自主演化【标志度★★★★，死代码复用】
- **现状**：太吾核心 NPC 自主修炼突破/结仇寻仇/迁徙通婚/传承衣钵；本游戏 npc-life-system 定义了无调度(0.2.5 接线后通电)，但无"自主演化"内容。
- **设计要点**（在 0.2.5 调度基础上加内容）：
  1. NPC 自主修炼：_cultivationProgress 达阈值触发突破（境界质变后世界整体升境）
  2. NPC 结仇寻仇：仇敌 NPC 主动找玩家/对方寻仇（事件链）
  3. NPC 迁徙：按日程/机缘迁城，世界人口流动
  4. NPC 通婚繁育：NPC 间结缘生子（v19.3 是 NPC 间的，复用）
  5. NPC 传承衣钵：师父死亡弟子继承功法（byMaster 索引 0.2.5 已修）
  6. NPC 老死/垂危触发后事（讣告邮件/遗产）
  7. 玩家可观察/干预：拜访老友发现他突破了、阻止仇敌突破
- **工程量**：~500 行（在 0.2.5 ~130 行调度之上）
- **涉及**：`js/npcs/npc-life-actor.js`、`js/npcs/npc-lineage.js`、`js/npcs/npc-life-system.js`、新建 `js/npcs/npc-autonomy.js`(寻仇/迁徙决策)
- **依赖**：0.2.5（调度）、0.2.4（关系四轨）、1.1（NPC 也能渡劫？可选）
- **验收**：长期游戏 NPC 会自主突破/迁徙/结仇/传承，世界不静止。
- **决策点**：NPC 自主演化速度（太快的世界玩家追不上，太慢没存在感）。

### 1.5 气运/机缘系统【标志度★★★★，完全没有】
- **现状**：鬼谷核心气运影响奇遇质量；本游戏无气运/机缘属性，奇遇纯 5% 随机。
- **设计要点**：
  1. 新增属性 `luck`（气运）+ `fortune`（机缘），受灵根/境界/装备/事件影响
  2. 气运影响奇遇触发概率（替代固定 5%）与奇遇稀有度权重（高气运多 RARE/EPIC）
  3. 机缘影响秘境宝物/敌人掉落质量
  4. 气运可主动消耗（"破机缘"换必成突破/必得宝物）
  5. 气运低触发倒霉事件（遇劫/物品损坏）
  6. 算命/占卜 NPC 可查气运（配合 2.6 天机推演）
  7. 飞升后香火（1.3）反向回馈凡间气运
- **工程量**：~400 行
- **涉及**：新建 `js/core/luck-system.js`、`js/event-system.js`(奇遇概率改造)、`js/loot-system.js`、`js/data.js`(属性)
- **依赖**：无（独立）
- **验收**：气运高低可见影响奇遇质量、可主动消耗、低气运有倒霉事件。
- **决策点**：气运是隐藏属性还是面板可见。

### 1.6 玩家建宗/经营【标志度★★★★，完全没有】
- **现状**：了不起核心建宗+招弟子+设施升级+护宗；本游戏只能加入门派。v19.18 玩家创宗计划未实装。
- **设计要点**：
  1. 元婴+可创建自己的宗门（选址灵脉、立派名、定道统）
  2. 招弟子：游历遇散修可招纳、外门杂役→内门核心（了不起外门内门）
  3. 宗门设施经营：扩建筑（练功房/炼丹房/炼器堂/护宗阵）、升级、维护费（3.3 经济 sink）
  4. 弟子管理：传功、派任务、外出历练、安抚
  5. 护宗战：敌对势力/妖兽攻山，玩家+弟子防守（1.1 阵法布阵）
  6. 宗门声望/资源/士气（复用 sect-internal 资源系统）
  7. 宗门大比（见 2.18 同门竞争）
- **工程量**：~800 行
- **涉及**：新建 `js/sects/player-sect-system.js`、`js/sects/disciple-management.js`、`js/house-system.js`(扩建筑)、`js/sects/sect-internal.js`(资源)
- **依赖**：0.2.5（NPC 弟子演化）、3.3（经济 sink）、2.12（阵法布阵）
- **验收**：可建宗、招弟子、经营设施、护宗、宗门大比。
- **决策点**：建宗境界门槛（元婴/化神）。

### 1.7 转世/轮回二周目【标志度★★★，完全没有】
- **现状**：觅长生保留属性重修、太吾传人；本游戏二周目只重置年龄。v19.13/14 轮回计划未实装。
- **设计要点**：
  1. 死亡/飞升后可选转世：保留前世 1 门功法记忆 + 1 个 NPC 羁绊 + 部分气运
  2. 转世后从凡人重修，但有"前世记忆"buff（修炼某功法更快、对某 NPC 有莫名亲切）
  3. 前世遗留：前世道侣/仇敌还在世界，转世后相遇有特殊剧情
  4. 多次转世解锁"宿慧"（跨世记忆觉醒，获前世技能）
  5. 轮回次数影响结局判定（多世修行者飞升更难/更易）
- **工程量**：~450 行
- **涉及**：新建 `js/core/reincarnation-system.js`、`js/core/soul-state.js`、`js/lifespan-system.js`、`js/npcs/npc-system.js`(羁绊继承)
- **依赖**：0.2.5（NPC 跨世）、1.1（渡劫失败可转世）、1.4（前世 NPC 还在）
- **验收**：死亡/飞升可转世、保留前世记忆/羁绊、多次转世有宿慧、前世 NPC 特殊剧情。
- **决策点**：转世保留多少（1 功法+1 羁绊 还是 更多）。

### 1.8 本命法宝/法宝成长【标志度★★★，完全没有】
- **现状**：了不起/觅长生长线养成锚点法宝成长；本游戏装备静态强化。
- **设计要点**：
  1. 金丹+可炼制本命法宝（绑定不可易主）
  2. 喂材料/灵液升级（独立等级，与装备强化并行）
  3. 觉醒技能：升级到阶解锁主动/被动技（配合 1.2 招式系统）
  4. 法宝受损需修复（战斗中被打耐久）
  5. 法宝有五行属性，与灵根/功法配合（0.2.2）
  6. 高阶法宝可化形（化神+ 法宝化形为灵兽/护法）
- **工程量**：~500 行
- **涉及**：新建 `js/equipment/bonded-artifact.js`、`js/enhancement.js`、`js/items-extended/`(法宝物品)
- **依赖**：1.2（觉醒技能接招式）、0.2.2（五行）
- **验收**：可炼本命法宝、喂材料升级、觉醒技能、受损修复、化形。
- **决策点**：法宝是否绑定不可换。

### 1.9 丹毒/丹方残卷/自创丹方【标志度★★★，完全没有】
- **现状**：觅长生残卷拼合+丹毒+自创；本游戏配方固定（17+8+6+4），丹药随便吃无丹毒。
- **设计要点**：
  1. 丹毒积累：服丹按丹药毒性积累丹毒值，高丹毒减修炼/破防/走火入魔风险
  2. 解毒丹/静心丹化解丹毒
  3. 丹方残卷：秘境/奇遇掉落残页，集齐 N 张拼合出完整丹方
  4. 自创丹方：高炼丹等级可自创丹方（材料组合 → 效果，玩家实验）
  5. 高品质丹药真实差异（修 0.2.7 bug + 极品丹额外效果，如极品回春丹+暴击回血）
  6. 丹炉品质影响炼丹（不同炉不同成功率/品质上限）
- **工程量**：~550 行
- **涉及**：新建 `js/crafting/pill-poison.js`、`js/crafting/recipe-fragments.js`、`js/crafting.js`(自创)、`js/items-extended/01-pills.js`(毒性强制)
- **依赖**：0.2.7（品质修复）、1.1（丹毒走火入魔联动）
- **验收**：服丹积累丹毒、残卷拼合、可自创丹方、极品丹真实更强。
- **决策点**：丹毒是否永久还是可化解。

### 1.10 高位面地图+御剑飞行【标志度★★★，完全没有】
- **现状**：鬼谷御剑自由飞行+觅长生灵界；本游戏只有凡界 17 城，travel 点对点菜单。
- **设计要点**：
  1. 筑基后解锁御剑飞行：地图从点对点菜单改为可飞行探索的连续地图（或大地图网格）
  2. 御剑消耗真气，高境界飞行更远更快
  3. 高位面地图：元婴+解锁灵界（新区域/NPC/材料）、化神+解锁魔界、飞升后天界（1.3）
  4. 各位面有特色：灵界灵气浓/魔界凶险掉魔气/天界香火
  5. 位面间传送阵/渡劫门
  6. 御剑战斗（配合 2.3 御剑术）：飞行中遇敌可空中战
- **工程量**：~700 行
- **涉及**：`js/map/randomMap.js`(改造为连续)、新建 `js/map/high-planes.js`、`js/location-system.js`、`js/travel-system.js`
- **依赖**：0.2.1（境界解锁）、1.2（御剑战斗）
- **验收**：筑基可御剑飞行探索、元婴解锁灵界、各位面有特色。
- **决策点**：连续大地图（重做 randomMap）还是节点大地图（轻量）。
