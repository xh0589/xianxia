## 一、对标审计结论（7 项）

### ❌ 完全缺失（市面标配但游戏无）
1. **自动存档**：原只有手动多存档槽（最多10个），无定时/关键节点自动存档
2. **键盘快捷键**：全程零快捷键
3. **贯穿主线故事**：只有「设施情境事件链」+零散奇遇，无主线叙事线+无最终Boss
4. **多阶段Boss战**：所有敌人单形态，无阶段切换/形态变化Boss
5. **音频**：完全无 BGM/音效（纯文本）

### ⚖️ 有但偏浅（机制在，深度不如市面）
6. **开局多样性**：角色创建只有灵根+属性分配，无出身/身世/天赋命格选择
7. **弟子培养**：师徒只有「传功加好感」一层，弟子不能独立成长/出师/反哺
8. **炼丹火候交互**：火候机制有但是「技能±随机」自动算，玩家不操作（鬼谷八荒火候是玩家实时控温QTE）

### ✅ 已有且不浅（核查确认，避免误判）
- 阵法（阵旗/阵眼/耐久/灵石维持/随身战阵+洞府阵）
- 炼丹机制层（火候/品质分档/炸炉/极品变体/imperial 变体）
- 血脉传承（npc-lineage 545 行跨代）
- 多存档槽（10 个）+导出
- 7 步新手教程+图鉴+世界大事记
- 节气/天劫多波/走火入魔/悟道树/本命法宝/灵脉/占卜/因果

## 二、新建 7 个文件

### 1. 自动存档 `js/core/auto-save.js`
- **独立键** `xianxia_auto_saves`，与手动档 `xianxia_save`/`xianxia_saves` 隔离，不抢占手动槽位
- **触发**：每 7 天（onNewDaySubscribe，同日去重）+ 突破成功 + 飞升 + 转世
- **保留**：最近 5 个自动档，每条含 `meta + state + trigger(定期/突破/飞升/转世) + timestamp`
- **关键函数**：`doAutoSave(trigger)` / `tickAutoSaveDay` / `refreshAutoSaveSlots` / `loadAutoSaveSlot`
- **复用**：`saveGame({autoMode,silent})` 收集存档（不写手动档不弹 toast）；`loadSaveData` 标准载入
- **UI**：存档面板「⚡ 自动存档」分区 + 载入按钮 + 上次自动保存时间

### 2. 主线+多阶段Boss `js/quest/main-storyline-arc.js`
- **叙事主线段**：`main_006 魔气东来`（清虚道人传讯查探异兆）→ `main_007 灵脉之劫·玄冥子`（凡间三阶段Boss）→ `main_008 天界魔气`（飞升后）→ `main_009 天界决战·魔仙`（终极三阶段Boss）
- **Boss 定义**：`MAIN_BOSSES.xuanming`（人形/魔化/灵体）+ `MAIN_BOSSES.xuanming_immortal`（魔仙·人形/法相/本源）
- **多阶段机制**：复用多波战斗 UI 模式（`_isMainStoryBoss` + `continueBossPhase`，仿 `_isHeavenlyTribulation`）；强度按玩家境界缩放 `_bossTierMul = 1 + tier*0.15`（仅本战内）
- **推进**：第三阶段名「玄冥子·灵体」/「魔仙·本源」作为 kill 目标，`notifyQuestKill` 发 `enemy:defeated`，species 精确匹配自动推进
- **结算**：`settleMainStoryBoss` 按 bossId 分支——凡间(灵石+2000/声望+200/气运+5) vs 魔仙(灵石+20000/声望+500/气运+20/真元+10000)；战败重伤不杀玩家（Boss退去可再战，主线不卡死）
- **进度**：`eventFlags['main_xuanming_defeated']` / `['main_xuanming_immortal_defeated']`
- **关键函数**：`startMainStoryBoss` / `continueBossPhase` / `settleMainStoryBoss` / `getMainBossProgress` / `openMainStoryPanel` / `acceptMainStoryQuest`

### 3. 开局出身天赋 `js/core/origin-talent.js`
- **出身 4 选 1**：寒门(铜+200/气运+5/历练+10) / 世家(灵石+300/铜+1000/名声+30/气运-5) / 散修(灵石+50/历练+30) / 弃徒(名声-20/历练+60)
- **天赋 5 选 1**：剑骨(攻+10%) / 铁骨(防+10%) / 灵机(真元+10%) / 道心(走火-30%) / 福星(气运+15)
- **应用**：`applyOriginTalentToCharData` 把出身资源写入既有字段（灵石/铜/名声/气运/历练）+ 存 `origin`/`talent` 标识
- **buff 接入**：`talentAtkMul`(buildPlayerBattleEntity) / `talentDefMul`(同) / `talentEssenceMul`(cultivationMeditate) / `talentHeartDemonMul`(走火入魔气机紊乱增长)
- **持久化**：`collectFullGameState` + `applyFullGameState` + saveData 手动 fallback 三处加 origin/talent
- **UI**：角色创建面板出身+天赋选择卡片（仿 gender-option 模式）+ 境界区常驻显示

### 4. 键盘快捷键 `js/core/keyboard-shortcuts.js`
- **映射**：C角色 B背包 M地图 K功法 Q任务 E装备 F势力 H洞府 P队伍 G灵兽 A活动 D日程 → `switchPanel`
- **Esc**：关闭战斗(`closeBattle`)或最上层弹窗(`.fixed.inset-0`)
- **空格**：战斗中点"继续"按钮
- **安全**：输入框内(INPUT/TEXTAREA/contentEditable)不响应、角色创建界面不响应面板键、战斗优先级最高
- **零状态**：纯 keydown 监听，无存档/无迁移

### 5. 炼丹火候QTE `js/crafting/fire-qte.js`
- **机制**：指针 0-100 来回扫动（setInterval 30ms），黄区(40-60)收火=80-100分极佳，近黄(25-75)=50-79，远=0-49
- **操作**：按空格或点「收火」，得分存 `window._alchemyFireBonus`，下次炼丹读取替代随机火候，消费即清
- **最小侵入**：只改 alchemy-compound 火候计算 2 行（有试火分用之，否则原随机），不重构既有 craft 同步流程
- **平衡修正**：得分 `min(bonus, skill+20)`——受炼制技能上限约束，防低技能玩家绕过技能（原随机上限 skill+20，保持一致）
- **空格**：仅 QTE 面板可见且非战斗时响应（与战斗空格互斥）
- **不存档**：`_alchemyFireBonus` 运行时临时变量，读档后需重新试火

### 6. 音效合成 `js/core/audio-synth.js`
- **Web Audio API 振荡器+增益包络** 合成 6 种提示音：突破(上行琶音C-E-G) / 战斗胜利(G-C) / 战败(下行) / 收火(清脆叮) / 炼丹(柔和) / 任务完成
- **自动触发**：EventBus 监听 `cultivation:breakthrough`(突破音) / `enemy:defeated`(胜利音) / `quest:completed`(任务音) / `item:crafted`(炼丹音)
- **浏览器策略**：首次用户交互 resume AudioContext（合规自动播放策略）
- **静音**：偏好存 localStorage `xianxia_sfx_muted`（用户偏好，非角色状态，不进角色存档）；设置面板 checkbox `toggleSfx()`

### 弟子培养 `js/sects/master-teach.js`（50行 → 完整培养链）
- **四阶段**：入门→小成→大成→圆满（按 `_cultivationProgress` 阈值 0/20/40/60 划分，复用 1.4 演化字段）

- **平衡**：约 12 次传功出师（耗 360 灵石），反哺 200+每日 2，约 80 天回本；出师弟子不腾位（防循环刷，50 弟子位上限）
- **UI**：`openDisciplePanel` 花名册+传功/出师按钮（自动刷新）
- **关键函数**：`teachDisciple` / `teachFirstDisciple` / `tryGraduateDisciple` / `dailyGraduatedFeedback` / `getDiscipleRoster` / `openDisciplePanel`

## 七、平衡点核查

| 项 | 平衡设计 |
|---|---|
| 火候QTE | `min(bonus, skill+20)` 防低技能绕过 |
| 出身资源 | trade-off：世家资源强但气运-5（长线奇遇少），寒门资源弱但气运+5+历练 |

| Boss 缩放 | `1+tier*0.15` 随玩家境界成长，飞升后魔仙 hp1500-3000*2.35≈3500-7000 |

## 八、设计原则遵守（用户要求）

- **代码结构合理**：复用既有系统（PlayerSect/npcManager/EventBus/onNewDaySubscribe/多波战斗UI），不新建平行状态；每个新系统独立文件+IIFE+window 导出
- **现实逻辑**：自动存档（关键节点）、主线叙事（凡间→飞升→天界）、弟子培养（传功→出师→反哺）、出身资源差异、走火入魔减免
- **机制平衡**：境界门槛+灵石成本+CD+概率上限+复用上限；无全局数值缩放；不读 DOM 作真值；不新增独立 localStorage 角色数据（仅静音偏好与自动档键）
- **强制规则.md**：每项改动前报 6 项 + 完成后报 5 项 + node --check + 端口 8000 验证
