# v19.17 教程/图鉴/世界日志 §11 实施计划

> 对标 v18.8 路线图 §11：教程（7 步引导）+ 图鉴（6 类）+ 世界大事记。
> 验收：7 步新手引导可永久关闭；6 类图鉴自动收集；世界大事记跨系统自动记录。

## 设计宪法

- 单一真源 + StateRegistry v1 + 镜像非真源
- 不复制战斗/存档系统
- 不引入"日限 N 次"配额
- 六大报告点 + 7 条禁止
- 不强制长教程（**仅任务式轻引导 + 可关闭**）
- 兼容：每个动作触发"first"事件自动记录

## 范围

## 批次 A：7 步新手引导

**文件**：`js/extensions/codex-tutorial.js`

**7 步**（路线图 §11.1）：
| id | 触发 | 永久关闭 |
|---|---|---|
| tut_first_cultivation | 第一次调修炼 | auto on close |
| tut_first_combat | 第一次战斗 | auto on close |
| tut_first_trade | 第一次买卖 | auto on close |
| tut_first_npc | 第一次 NPC 互动 | auto on close |
| tut_first_sect | 第一次加入门派 | auto on close |
| tut_first_craft | 第一次炼丹/炼器 | auto on close |
| tut_first_dungeon | 第一次秘境 | auto on close |

**API**：
```js
window.CodexTutorial = {
  trigger(stepId) → {ok, dismissed: bool}   // 检查是否首次
  dismiss(stepId) → bool                      // 永久关闭
  isDismissed(stepId) → bool
  getState() → {dismissed: {}, current: null}
  listSteps() → array
}
```

**钩子**：每个 v19.x 系统在第一次相关动作时调 `trigger(stepId)`

## 批次 B：6 类图鉴

**6 类**（路线图 §11.2）：
- codex_gongfa：功法图鉴
- codex_beast：灵兽图鉴
- codex_recipe：丹方图鉴
- codex_sect：门派图鉴
- codex_dungeon：秘境发现记录
- codex_world：世界大事记

**API**：
```js
window.Codex = {
  discover(codexId, itemId, info) → {ok, entry}    // 自动去重
  getEntries(codexId) → array
  getEntry(codexId, itemId) → entry
  getProgress(codexId) → {discovered, total, percent}
  markSeen(codexId, itemId) → bool                  // 标记已查看
  getState() → {codexGongfa, codexBeast, ...}
}
```

**钩子**：
- v19.4 AlchemyCompound 成功 → `codex_recipe.discover('codex_recipe', pillId, ...)`
- v19.5 ForgingCompound → `codex_gongfa`（不对，gongfa 是功法）
- v19.6 TalismanAdvanced → `codex_recipe` 同
- v19.7 FormationSystem → `codex_gongfa` 不对，应该是 `codex_recipe`（formation 配方）
- v19.8 PuppetSystem craft → `codex_recipe`
- v19.9 DungeonDynamic enter → `codex_dungeon`
- v19.12 BeastEcosystem placed → `codex_beast`
- v19.15 NarrativeConsequence apply → `codex_world`

> v19.17 提供 API，**v20.x 集成** 各 v19.x 系统的第一次成功调用 discover

## 批次 C：世界大事记

**自动记录**：
- 玩家突破大境界 → recordBreakthrough
- 玩家加入/离开门派 → recordSectChange
- 玩家击杀/被击败 → recordCombat
- 玩家结婚/生子 → recordLife
- 玩家轮回 → recordReincarnation
- 玩家 NPC 好感度 ≥ 80 → recordBond
- 玩家创宗 → recordAchievement

**结构**：
```js
{ id, type, day, title, text, refs: {npcId?, sectId?, ...} }
```

**API**：
```js
window.WorldJournal = {
  record(event) → {ok, entry}
  getEntries(type?) → array
  getByDayRange(startDay, endDay) → array
  getByType(type) → array
  getRecent(limit) → array
  getState() → {entries: []}
}
```

**钩子**：
- v19.14 onPlayerDeath → recordReincarnation
- v19.15 applyConsequence ('worldFlag') → recordAchievement
- v19.16 addCompanion → recordLife

> v19.17 提供 API，**v20.x 集成**
