# v18.8 当前内容深度复核（2026-08-26）

本文件只记录**当前真实代码**仍存在的内容深度差距，不继承旧版本差距报告里已经过时的结论。

## 本轮已补

1. **长期闭关**：此前玩家最长只有“一天”打坐；v18.8 增加七日 / 一月 / 一季闭关，并逐日推进权威时间系统，让 NPC、寿元、宗门日结和世界状态继续运行。
2. **宗门特色资源真实化**：此前 `sects-deep-data.js` 写着“产出+X/日”，但没有任何日产入库。v18.8 已接入宗门库存、弟子用度、日净产出与 StateRegistry 存档。
3. **修罗宫/百花谷私人线资格**：游客、异派、未见面、离开门派、远程档案均不能进入掌门私人事件；底层直接调用同样受门禁。

## 仍然明显偏浅 / 缺失（按优先级）

### P1：宗门领地与资源争夺

当前已有：门派资源、士气、影响力、外交、战争、灵矿/药园等“名词和局部系统”。

缺口：世界地图上的灵矿、秘境、药田等还不是**可被宗门占领、争夺、易手**的战略对象；因此宗门资源虽然开始真实生产，仍缺“为什么要抢、抢到后世界如何改变”的外循环。

建议下一步：把现有矿脉/秘境节点加 `ownerSect`，宗门战争/外交可以改变所有权；所有权反过来影响日产、坊市物价、任务与 NPC 活动。

对标：《鬼谷八荒》官方介绍明确把掌门攻防、灵矿等珍贵资源争夺和征服其他宗门放在同一宗门经营链里；《了不起的修仙模拟器》强调 NPC 宗门互相作用并持续改变势力与影响力。

### P1：NPC 家庭 / 代际 / 衣钵传承

当前已有：NPC 年龄、寿元、死亡、关系、师徒、道侣、朋友/仇敌、自主修炼与活动。

缺口：全工程没有真正的婚姻、子女、后代、继承人系统。寿元和死亡因此主要是“角色消失”，没有形成跨几十年/几百年的世界历史。

建议下一步：先做轻量版，不必变成家族模拟器——道侣可结契；重要 NPC 可有子嗣/亲传；NPC 死亡后遗物、功法或职位可由亲传/后代继承；掌门死亡触发门派继任事件。

对标：《太吾绘卷》官方页明确包含 NPC 衰老、生病、死亡、结婚、生子和将毕生武学传给下一任继承人；《修仙家族模拟器》把父母、道侣、弟子、师尊、宗门、家族、好友与血脉传承连成长期关系网。

### P1：宗门大比 / 弟子竞争

当前已有：门派职位、任务、NPC 弟子、晋升、演武场、竞技场。

缺口：没有宗门小比/大比/席位竞争。玩家晋升主要依赖贡献值与条件检查，缺少“和同门竞争”的门派生活事件。

建议下一步：每季一次小比、每年一次大比；按职位分组，复用现有战斗系统生成同门对手；成绩影响贡献、师父评价、派系影响和晋升资格。

对标：《鬼谷八荒》官方页明确写到弟子会完成宗门任务、参加宗门比试并为宗门争夺荣耀与资源。

### P2：炼丹 / 炼器仍偏固定配方

当前已有：355 个有效物品、37 个有效配方、炼丹/炼器/符箓/强化、生活技能与工坊折扣。

缺口：主要还是“固定材料 → 固定配方 → 固定成品”。材料本身对成品个体属性的影响较弱，玩家缺少试方、替材、火候、器胚路线等决策。

建议下一步：先给高阶配方增加“主材 + 辅材槽”，辅材改变成品词缀/品质概率，而不是再增加几十条固定配方。

对标：《了不起的修仙模拟器》官方页明确说明制作成品会继承原材料特性；《修仙家族模拟器》则把炼器、炼丹、炼符、傀儡、御兽、阵法、种植、采矿作为互相供给的修真百艺。

### P2：傀儡 / 阵法存在题材引用，但独立玩法不足

当前已有：队伍阵型、天然阵法临时增益、机关/傀儡相关敌人与门派文案、神机门技能文本。

缺口：没有真正的“制作傀儡并编入队伍”玩法，也没有可布置/消耗材料/改变战斗或洞府环境的阵法系统。

建议下一步：优先做一个可制造的机关傀儡伙伴 + 三种基础阵盘（聚灵/护山/困敌），复用现有队伍、制作、buff 和洞府系统，不另起大框架。

### P3：声音与新手引导仍为空

当前工程没有实际音频资源/Audio 播放链，也没有正式教程/新手引导系统。这不是“仙侠深度”本身，但会显著影响成品感和第一次游玩的理解成本。
