## 批次 A：修 BUG（必须）

**文件**：`js/map/randomMap.js` + 新 `js/extensions/beast-ecosystem.js`
**修改点**：
1. `tryBeastAmbush` 加 `e.isDead || e.hp <= 0` 过滤
2. `tryBeastAmbush` 跳过 `e.isCorpse` 标志
3. `onCellClick` 同样过滤：移动时只触发生物（非尸体）
4. **真正方案**：把所有 `cell.entities[*]` 加 `_alive` 标记；战败后 app.js 标记 `_alive=false`

> 但 app.js 战败逻辑没在 randomMap 引用 → **本计划由 beast-ecosystem 提供统一 patch**：
> 暴露 `window.markEntityDead(cellRef, entityIdx)`，让 app.js 调用
> tryBeastAmbush 内检查 `e._alive !== false`

## 批次 B：灵兽按地区/地形分布

**文件**：`js/extensions/beast-ecosystem.js`

**10 灵兽 → 7 地区 × 地形分布**：
| 灵兽 | 主出现地区 | 次出现地形 | 等级 |
|---|---|---|---|
| 灵狐 | 中州/南疆 | 森林 | 5 |
| 雷鹰 | 天空/东荒 | 山地 | 12 |
| 龙龟 | 东海/东南海域 | 水域 | 18 |
| 冰蛇 | 北冥 | 雪地/冻土 | 15 |
| 风狼 | 西漠/蜀地 | 平原 | 8 |
| 火凤 | 南疆 | 火山 | 22 |
| 玄龟 | 东海 | 水域 | 16 |
| 雷兽 | 天空 | 山地 | 20 |
| 仙鹤 | 天空/中州 | 灵泉 | 10 |
| 黑熊 | 北冥/中州 | 森林 | 6 |

**API**：
```js
window.BeastEcosystem = {
  // 在地图生成后调用，给地图注入灵兽
  populateBeasts(map, region) → {placed, byBeast}
  // 按地形过滤可放置格
  getPlaceableCells(map, terrainTypes) → [{x, y, terrain}]
  // 灵兽按地区权重
  getBeastPoolForRegion(region, terrain) → [{beastId, weight}]
  // 标记尸体
  markEntityDead(cellRef, entityIdx) → bool
  isEntityDead(entity) → bool
}
```

**触发条件**：`currentMap` 生成后调一次 `populateBeasts`；玩家捕获后从 cell.entities 移除
