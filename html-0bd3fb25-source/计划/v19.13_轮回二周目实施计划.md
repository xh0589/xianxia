# v19.13 轮回/二周目 继承系统 §8 实施计划

> 对标 v18.8 路线图 §8：把"轮回"做成修仙主题系统；6 类前世遗产点；5 类继承选择；世界连续性。
> 验收：死亡/飞升/转世时计算前世遗产点；下一世可继承 5 类（记忆/法器/缘分/气运/洞府）；前世传说留存 NPC 世界。

## 设计宪法

- 单一真源 + StateRegistry v1 + 镜像非真源
- 不复制战斗/存档系统
- 不引入"日限 N 次"配额
- 六大报告点 + 7 条禁止
- 不动 `startNewGamePlus()` 主入口（**仅提供 inheritance API**，由 NG+ 流程调用）
- 不动 GameState 主存档（**前世遗产点存 StateRegistry v1**）

## 范围

| 在做 | 不做 |
|---|---|
| 6 类遗产点计算（境界/关系/职位/事件/成就/寿终） | 重写 startNewGamePlus |
| 5 类轮回选项（记忆/法器/缘分/气运/洞府） | 真正创建新存档（v20.x） |
| 前世传说留存（NPC 留存 / 碑文 / 遗物） | 完整 NPC 后裔系统（v20.x） |
| StateRegistry v1 `reincarnationConfig` | UI 入口（v20.x） |
| 单元测试 ≥ 25 条 | 浏览器 e2e |

## 批次 A：前世遗产点生成

**文件**：`js/extensions/reincarnation.js`

**6 类遗产点**（路线图 §8）：
1. **境界**：最高境界（练气=1/筑基=3/金丹=8/元婴=20/化神=50/渡劫=120/大乘=300）
2. **重要关系**：NPC 好感≥80 数量（每 NPC +5，最高 +50）
3. **宗门职位**：掌门=80/长老=40/堂主=20/弟子=5
4. **大事件选择**：影响世界走向的关键决策数（每事件 +3）
5. **炼丹/炼器成就**：炼制过 100+ 品质丹药 +15 / 10+ 极品法器 +20
6. **寿终正寝**：自然死亡（非战死）+30；战死+0

> 总遗产点 = 累加
> 例：元婴 + 掌门 + 20 关系 + 5 事件 + 10 丹药 + 寿终 = 20+80+50+15+15+30 = 210 遗产点

**API**：
```js
window.Reincarnation = {
  computeInheritancePoints(playerData) → {total, breakdown}
  startReincarnation(playerData, reason) → {ok, summary, legacyPoints}
  listLegacyTypes() → array
  canReincarnate(playerData) → bool
  // 5 类继承选项（批次 B）
  grantInheritance(nextLifeData, choice) → {ok, applied: […]}
  // 世界连续性（批次 C）
  preserveWorldMemory(playerData) → {ok, legacyRecords}
  getLegacyRecords() → array
  addLegacyRecord(record) → bool
}
```

**reasons**：'death-combat'（战死）/'death-natural'（寿终）/'ascend'（飞升）/'voluntary'（主动转世）

## 批次 B：5 类轮回选项

每类选项消耗不同遗产点：
- **前世记忆**（功法熟练度）：80 点 → 选 1 个功法保留 50% 熟练
- **本命法器**：120 点 → 1 件传说品质法器作为开局装备
- **旧友缘分**：60 点 → 下一世 1 个 NPC 起始好感+30
- **先天气运**：100 点 → 1 个特殊气运（灵根变异/特殊体质）
- **前世洞府**：150 点 → 1 个洞府位置解锁（含部分基础资源）

**API**：`grantInheritance(nextLifeData, choice)` → 校验遗产点足够 → 应用到下辈子

## 批次 C：世界连续性

**前世传说留存**（路线图 §8 末段）：
- 每条前世记录 = `{playerName, finalRealm, lifeSpan, deeds: [string], worldDay}`
- NPC 可"记得"前世弟子 → 通过 addLegacyRecord 写入
- 玩家重玩时：读取 `getLegacyRecords()` → 决定 NPC 起始态度/碑文/遗物

**10 种 deed**（前世成就记录）：
- 'founded-sect'（创宗）
- 'mastered-pill'（炼丹宗师）
- 'mastered-weapon'（炼器宗师）
- 'conquered-dungeon'（通关秘境）
- 'won-tournament'（宗门大比冠军）
- 'married'（结道侣）
- 'had-children'（有后代）
- 'saved-sect'（救宗）
- 'discovered'（发现新秘境）
- 'achieved-breakthrough'（突破大境界）

**API**：`addLegacyRecord({playerName, finalRealm, lifeSpan, deeds:['founded-sect']})`

## 批次 D：StateRegistry + 事件总线

**StateRegistry v1** `reincarnationConfig`
- inheritancePool: 前世遗产点临时缓存
- legacyRecords: 全部前世记录（最多 10 条）
- nextLifeInheritance: 下辈子待应用的继承

**事件总线 3 个**：
- `reincarnation:start` / `reincarnation:inherit` / `reincarnation:legacy`
