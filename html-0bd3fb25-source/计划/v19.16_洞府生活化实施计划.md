# v19.16 洞府灵田生活化 §10 实施计划

> 对标 v18.8 路线图 §10：洞府设施槽系统 + 同伴使用洞府。

## 设计宪法

- 单一真源 + StateRegistry v1 + 镜像非真源

- 六大报告点 + 7 条禁止
- 不动既有 4 档洞府 / 4 种作物数值（**新增"设施"独立层**）
- 兼容：玩家初始有 1 洞府 + 2 槽位

**API**：
```js
window.CaveFacilities = {
  install(caveId, facilityId) → {ok, slot, buff}
  uninstall(caveId, slot) → {ok, removed}
  getFacilities(caveId) → [{slot, facilityId, ...}]
  getAvailableSlots(caveId) → number
  addCompanion(caveId, npcId, role) → {ok, companionId}
  removeCompanion(caveId, companionId) → bool
  assignCompanionToFacility(caveId, companionId, slot) → {ok}
  tickDay(caveId) → {events:[], buffs:[]}
  getBuff(caveId, attrKey) → mul
  getState() → {caves}
  listFacilityTypes() → array
}
```

## 批次 B：同伴使用洞府

**同伴** = `{companionId, npcId, role, slot, joinedDay}`：
- 道侣（dao_companion）可分配：灵田 / 丹房 / 客房
- 弟子（disciple）可分配：藏书阁 / 灵兽栏 / 闭关室
- 重要 NPC（special_npc）可分配：丹房（炼丹师）/ 炼器台（炼器师）/ 藏书阁

**同伴技能影响 buff**：
- 道侣 affection ≥ 80 → 灵田 buff ×1.2
- 弟子 skill ≥ 50 → 藏书阁 buff ×1.3
- 重要 NPC profession='alchemist' → 丹房 buff ×1.5

## 批次 C：小事件 + buff 联动

**每日 tickDay 生成事件**：
- 10% 触发：`"道侣在灵田发现灵药"` → +1 随机材料
- 10% 触发：`"弟子在藏书阁有感悟"` → expBoost 1 天 +10%
- 5% 触发：`"重要 NPC 来访，谈话"` → rumor + npcRelation +10
- 8% 触发：`"闭关室灵气波动"` → 修炼成功率 +5% 1 天
- ...

**buff 联动**：
- alchemy skill 直接加到 v19.4 AlchemyCompound
- qiRegen 加到 daily 资源产出
- expBoost 加到 WorldCalendar 出关摘要

> v19.16 **只暴露 getter**，让其他系统读取

## 批次 D：StateRegistry + 事件总线
