# v20.0 主循环真集成实施计划

> 对标 session 收口：v18.9~v19.20 全部 API 已落地，但多数 `tickDay` / 捕捉池 / 物价乘数从未接入 `newDay` 与真实玩法。
> 验收：跨天时世界真正推进；兽潮改变捕捉与遭遇；坊市价吃地区供需；洞府设施日结；灵兽园 buff 进入培养。

## 设计宪法

- 单一真源：日结只挂 `EventBus.on('newDay')`，不包装 `timeSystem.onNewDay`
- 镜像非真源：日历只登记兽潮开始/结束，不改世界事件触发权
- 不新增独立 localStorage 键
- 不引入「日限 N 次」配额（培养日限是既有旧机制，本次不扩）
- 不复制战斗/存档系统
- 禁止只暴露 API 不接闭环

## 涉及状态 / API / 存档 / 事件 / 迁移 / 验收

1. **状态唯一所有者**
   - `BeastTideAndGarden` → `beastTideAndGarden`
   - `BeastEvolution` → `beastEvolution`
   - `MarketDynamic` → `marketConfig`
   - `ResourcePoints` → `resourcePointConfig`
   - `PlayerSect` → `playerSect`
   - `PuppetSystem` → `puppetConfig`
   - `CaveFacilities` → `caveSystem`
   - `DungeonDynamic` → `dungeonDynamic`
   - `NarrativeConsequence` → `narrativeConsequence`
   - 世界事件 `activeWorldEvents` 仍由 `world-events.js` 持有
2. **调用的公开 API**：各模块既有 `tickDay` / `triggerTide` / `priceMul` / `generateDaily` / `processDay` / `initBeast` / `discover` / `record`
3. **存档字段**：不新增 StateRegistry 键；WorldCalendar 继续镜像登记
4. **事件**：消费 `newDay`；兽潮开始/结束发日历登记 + 世界大事记；不新增平行总线
5. **旧存档迁移**：不需要（缺段按空表）
6. **验收**：`tests/world-loop-node.js` ≥ 40 条 + 既有套件全过 + `node --check`
